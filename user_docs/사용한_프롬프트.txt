### 처음 요청 프롬프트
모바일 웹 커뮤니티 서비스를 만들거야. 하단 탭은 홈(피드), 내정보(프로필),설정 3개야
기능: 회원가입, 로그인, 로그아웃 / 글 작성, 목록, 상세 / 댓글, 좋아요 / 프로필 (닉네임, 프로필이미지, 내가쓴글) /
다른 유저의 프로필 보기
기술스택 : Next.js, Supabase, tailwind, vercel
이 앱의 요구사항 정의서를 만들어줘. 1. 기능목록, 2. 각 기능 상세 요구사항, 3. 사용자 흐름, 4. 화면 목록,
5. 간단한 데이터 개요를 포함해서 docs/requirements.md 파일로 저장해줘

####################################################
 @docs/requirements.md 와 @docs/design.md 를 읽고,
 이 커뮤니티 서비스를 Next.js + Supabase 로 구현하기 위한 개발 계확을 세워줘.

 아래를 포함해줘 :
 1. 폴더 구조
 2. 페이지/라우트 목록
 3. DB 테이블 개요
 4. 구현 순서 (인증 / 피드 / 댓글 좋아요 / 프로필 / 배포 등)
 5. 주의점 (RLS 접근 권한, 로그인 등)
